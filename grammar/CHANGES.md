# AST changes

## 2026-10-12 — initial schema (0.1.0)

Initial public node and field names are published in `src/node-types.json`.
There are no renames from an earlier published schema.

Future changes must preserve these names. If a rename is unavoidable, append
every old node/field name, its replacement, the reason, and migration guidance
here. Additive node types or fields should also be documented.
